# 🏠 Marketplace API

Бэкенд-часть веб-приложения для размещения объявлений с возможностью комментирования и управления пользователями.
## 📋 Описание проекта

REST API для онлайн-доски объявлений. Пользователи могут регистрироваться, размещать объявления, оставлять комментарии, загружать изображения и управлять своим профилем.

## 🚀 Функциональность

### 🔐 Авторизация и аутентификация
- Регистрация новых пользователей
- Авторизация по Basic Auth
- Ролевая модель (USER, ADMIN)
- Смена пароля

### 👤 Управление пользователями
- Просмотр и редактирование профиля
- Загрузка и обновление аватара
- Смена пароля

### 📢 Объявления (Ads)
- Создание, редактирование, удаление объявлений
- Поиск и фильтрация объявлений
- Загрузка изображений для объявлений
- Просмотр своих объявлений
- Расширенная информация об объявлении

### 💬 Комментарии
- Добавление комментариев к объявлениям
- Редактирование и удаление комментариев
- Просмотр всех комментариев объявления

## 🛠️ Технологии и библиотеки

### Backend
- **Java 11**
- **Spring Boot 2.7.15**
- **Spring Security** - аутентификация и авторизация
- **Spring Data JPA** - работа с базой данных
- **PostgreSQL** - реляционная база данных
- **Lombok** - сокращение boilerplate кода
- **Swagger/OpenAPI 3** - документация API

### Инфраструктура
- **Maven** - управление зависимостями
- **Docker** - контейнеризация
- **Docker Compose** - оркестрация контейнеров

### Тестирование
- **JUnit 5** - unit-тестирование
- **Spring Boot Test** - интеграционное тестирование
- **Mockito** - мокирование зависимостей
## 🗄️ База данных

### Сущности
1. **UserEntity** - пользователи системы
    - id, email, password, firstName, lastName, phone, role, imageUrl
    - Связи: один-ко-многим с AdEntity и CommentEntity

2. **AdEntity** - объявления
    - pk, title, price, description, imageUrl, createdAt
    - Связи: многие-к-одному с UserEntity, один-ко-многим с CommentEntity

3. **CommentEntity** - комментарии
    - pk, text, createdAt
    - Связи: многие-к-одному с UserEntity и AdEntity

## 🔧 Установка и запуск

### Предварительные требования
- Java 11 или выше
- Maven 3.6+
- Docker и Docker Compose
- PostgreSQL (если запуск без Docker)-
  🌐 API Endpoints
  Базовый URL: http://localhost:8080
  📚 Документация API
  После запуска приложения документация доступна по адресам:

Swagger UI: http://localhost:8080/swagger-ui.html

OpenAPI спецификация: http://localhost:8080/v3/api-docs

🔒 Безопасность
Basic Authentication для всех запросов (кроме публичных)

BCrypt для хеширования паролей

Ролевая модель: USER (обычные права), ADMIN (полные права)

Проверка авторства: пользователи могут редактировать/удалять только свои данные

CORS настроен для http://localhost:3000
